# 🔢 Prime Number Checker

A real-time, highly optimized Prime Number Checker built with **React** and **Tailwind CSS**. 

This project focuses on clean event handling, avoiding stale state issues, and implementing an efficient mathematical algorithm for real-time validation.

---

### ✨ Features

- **Real-Time Validation:** Instantly evaluates if a number is Prime as the user types.
- **Optimized Algorithm:** Uses `Math.sqrt(num)` for an efficient $O(\sqrt{n})$ time complexity.
- **Edge Case Handling:** Robustly handles `0`, `1`, negatives, and non-integers without breaking the UI.
- **Conditional Rendering:** Uses the Logical AND (`&&`) operator for clean, inline UI toggling.

---

- ️ **React** (Functional Components & `useState` Hook)
- 🎨 **Tailwind CSS** (Utility-first styling)
